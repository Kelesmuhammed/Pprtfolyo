# 🚀 Muhammed Keleş - Kişisel Portfolyo Projesi

Bu repository, web geliştirme temellerimi tazelemek, paslanan bilgilerimi silmek ve kendi ellerimle tasarladığım samimi kişisel portfolyo sitemi barındırır. 

Sıradan, aşırı simetrik ve yapay zeka ürünü olduğu bellİ olan tasarımlardan kaçınarak; atölye disiplinimi, donanım/IoT merakımı ve yazılım öğrenme sürecimi yansıtan sıcak bir "Maker" stili benimsenmiştir.

## 🛠️ Kullanılan Teknolojiler

*   **HTML5 & CSS3** (Özel kömür/grafit teması ve el yapımı dokunuşlar)
*   **Bootstrap 5** (Responsive / Mobil uyumlu yapı)
*   **JavaScript & Typed.js** (Dinamik yazı animasyonları)
*   **Boxicons & Bootstrap Icons** (Minimalist ikon setleri)
